# UI 점검표

승인된 서사형 UI와 뉴트럴·블루 Foundation의 시각·동작 회귀를 확인한다. 범위가 한 화면에 국한되면 해당 화면만, 라우터·공통 레이아웃·토큰 변경이면 전체를 확인한다.

| 화면·상태 | 기대 결과 |
| --- | --- |
| 홈 `/` | 히어로, 프로젝트 진입, Approach, Contact가 표시된다. |
| `/projects/` | 15개 프로젝트 목록, 이미지, 상세 링크가 표시된다. |
| 16개 상세 경로 직접 열기 | 각 고유 제목·설명·본문·이미지·돌아가기 링크가 유지된다. |
| 라이트·다크 토글 후 새로고침 | 테마가 `portfolio-theme` 값으로 복원된다. |
| 첫 화면 히어로 | 큰 제목·설명·CTA가 처음부터 표시되고 왼쪽 rail이 데스크톱에서 표시된다. |
| reduced-motion | 장식적 전환이 생략되고 콘텐츠를 읽을 수 있다. |
| 데스크톱·모바일, 키보드 | 가로 잘림 없이 탐색·스킵 링크·포커스가 동작한다. |
| 콘솔·네트워크 | JS 오류와 누락된 이미지·스타일이 없다. |

검사한 브라우저·뷰포트와 pass/fail/not-run을 Handoff에 기록한다.
