# 포트폴리오 작업 흐름

전역 `AGENTS.md`의 Planner, Designer, Implementer, Reviewer 흐름을 따른다. 이 저장소의 추가 기준은 [위험·검증 Gate](gates.md)와 [UI 점검표](ui-smoke-checklist.md)에 있다.

승인된 서사형 디자인과 뉴트럴·블루 토큰을 기준으로 16개 URL, 페이지별 메타·본문, 정적 이미지와 라이트·다크 테마의 회귀를 검토한다. 문서 셸과 스타일의 작성 원본은 TypeScript/TSX이며 `dist/`는 빌드 시 생성한다. 새 시각 방향은 전역 디자인 승인 절차를 먼저 따른다.
