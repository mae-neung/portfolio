Project 05 · 2021

한큐플랜트

상품 등록부터 견적·결제·납품 관리까지 지원하는 B2B 식물 거래 플랫폼입니다.

Role
프론트엔드 개발
Period
2021.10 — 2021.12
Stack
React · FastAPI · TypeScript
Scope
상품 · 견적 · 주문 · 납품

01 / Overview

프로젝트 소개

조경회사, 입찰기업, 화훼·관목 농가 등 식물 거래 관계자가 모바일 환경에서 상품을 등록하고 견적을 주고받을 수 있도록 만든 B2B 식물 거래 플랫폼입니다.

02 / Features

주요 기능

  • 도매 식물 상품 등록과 목록 조회
  • 직접 입력·이미지·엑셀 파일을 활용한 견적 요청
  • 판매회원의 견적 제안과 자동 견적함
  • 주문·결제·거래 내역·납품 캘린더 관리

03 / Technology

기술 스택 및 프로젝트 화면

  • React와 TypeScript 기반 프론트엔드
  • FastAPI 기반 백엔드 API 연동
