01 / Overview

프로젝트 소개

비영리단체 더 브릿지의 미션과 사회적 비즈니스 콘텐츠를 소개하고, 캠페인 탐색부터 외부 결제까지 기부 흐름을 제공하는 공식 웹사이트 리뉴얼 프로젝트입니다.

02 / Features

주요 기능

  • 단체 소개와 사회적 비즈니스 콘텐츠
  • 운영 콘텐츠를 관리하는 CMS
  • 캠페인 탐색과 외부 PG 기부 결제
  • 외부 PG 구간을 포함한 Google Analytics 전환 추적
  • 로그인과 사용자 상태 관리
